---
title: Keyboard shortcuts
description: Keyboard shortcuts for the app, the explorer, and the editor.
---

The shortcuts below use the macOS keys. On Windows and Linux, use Ctrl for ⌘ and Alt for ⌥. Some shortcuts do different things in the explorer and in the editor; they apply where the focus is.

## App

| Action        | Shortcut |
| ------------- | -------- |
| Search or ask | ⌘K       |
| Settings      | ⌘,       |

## Explorer

| Action                     | Shortcut             |
| -------------------------- | -------------------- |
| New entry                  | ⌘E                   |
| New collection             | ⌘⇧C                  |
| Copy ID                    | ⌘⌥C                  |
| Rename                     | F2                   |
| Delete                     | ⌘⌫                   |
| Move between items         | ↑ and ↓              |
| Open or close a collection | → and ←              |
| First or last item         | Home and End         |
| Select an item             | Space                |
| Open an entry              | Enter                |
| Open the menu of an item   | ⇧F10 or the menu key |

To go to an item, type the first letters of its name.

## Editor: text

| Action        | Shortcut |
| ------------- | -------- |
| Bold          | ⌘B       |
| Italic        | ⌘I       |
| Strikethrough | ⌘⇧X      |
| Code          | ⌘E       |
| Link          | ⌘K       |
| Highlight     | ⌘⇧H      |
| Undo          | ⌘Z       |
| Redo          | ⌘⇧Z      |

## Editor: blocks

| Action                 | Shortcut   |
| ---------------------- | ---------- |
| Heading 1 to Heading 6 | ⌘⌥1 to ⌘⌥6 |
| Bullet list            | ⌘⇧8        |
| Ordered list           | ⌘⇧7        |
| Task list              | ⌘⇧9        |
| Blockquote             | ⌘⇧B        |
| Code block             | ⌘⌥C        |
| Slash menu             | /          |
| Format an element tag  | ⌘⇧F        |

For Markdown shortcuts such as `## ` and `- `, see [Editor](/docs/writing/editor/).
