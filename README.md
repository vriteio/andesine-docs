# Andesine Docs

The source of the [Andesine documentation](https://andesine.app/docs), built with
[Andesine Pages](https://github.com/vriteio/andesine/tree/main/packages/public/pages).

The content is written in Andesine and synced to `src/content/docs` with GitHub Sync. Edit it in
Andesine. Changes to the files here also sync back to Andesine.

```sh
npm install
npm run build
```
